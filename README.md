# Slidr – enkel oppskrift

1. Lag konto på github.com og vercel.com (velg "Continue with GitHub").
2. På GitHub: New repository → "Upload files" → dra inn ALT fra denne mappen → Commit.
3. Lag API-nøkkel på console.anthropic.com (Billing: legg inn litt kreditt, f.eks. $5. API Keys: Create key, kopier den).
4. På Vercel: Add New → Project → velg repoet → åpne "Environment Variables":
   ANTHROPIC_API_KEY = nøkkelen
   APP_PASSWORD = et passord du velger
5. Trykk Deploy. Åpne lenken du får. Ferdig.
